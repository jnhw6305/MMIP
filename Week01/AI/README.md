# Week 01：AI 輔助與人工驗證紀錄

本週使用 AI 協助規劃與修改 Python／OpenCV 程式、解讀錯誤訊息及整理實驗報告。本檔是協作摘要，**不是完整對話逐字稿**；程式輸出仍以實際執行與目視檢查為準。

| 題目 | AI 協助的工作 | 人工／實驗驗證 |
| --- | --- | --- |
| Quiz 1 | 協助加入 NumPy 灰階公式、重複計時與差異圖 | 使用彩色影像執行；確認兩種結果在該影像逐像素相同，差異圖全黑並非故障。 |
| Quiz 2 | 協助實作 NumPy 直方圖、CDF、LUT 及前後比較圖 | 執行並查看影像與直方圖；檢查報告中的亮度分布和時間數據。 |
| Quiz 3 | 協助將單張校正改成批次、自動找角點；依新增實拍修正低對比邊緣與藍色書封偵測 | 四張實拍均產圖，逐張檢查角點與校正圖；另以 [受控劣化測試](../../results/quiz3_advanced/summary.md)記錄失敗條件。 |
| Quiz 4 | 協助比較 SIFT、OpenCV Stitcher、亮度／裁切條件與 CLAHE | 檢查匹配數、RANSAC 內點及代表性拼接圖；辨認黑邊、接縫與重影，未把「產圖成功」寫成「畫質完美」。 |

使用 AI 時曾要求「自動找角點、批次輸出校正圖與角點標記圖」、「作業1和作業2的進階也一起完成」等。實際照片由本人提供，AI 沒有生成冒充實拍的影像；Quiz 3 的額外亮度／模糊條件和 Quiz 4 的亮度／裁切條件都明確標為軟體模擬。限制、失敗案例與結果來源詳見各題報告。
